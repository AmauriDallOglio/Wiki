# O que você pode usar GRATUITAMENTE no Azure

Este documento detalha os serviços gratuitos disponíveis no Azure, focando em ferramentas de Inteligência Artificial que podem ser utilizadas para diversos propósitos, desde análise de texto até processamento de fala e documentos. O objetivo é fornecer um guia claro sobre como iniciar o uso dessas ferramentas sem custos iniciais, destacando seus limites e aplicações.

###  1. Language Studio

O Azure Language Studio é uma plataforma robusta e altamente recomendada para explorar as capacidades de processamento de linguagem natural (PLN) do Azure. Através dele, é possível realizar diversas análises em textos, como a **Análise de Sentimento**, que identifica a polaridade emocional de um texto; a **Extração de Frases-chave**, que resume os pontos principais de um conteúdo; a **Detecção de Idioma**, que identifica automaticamente a língua em que um texto foi escrito; e a **Extração de Entidades**, que reconhece e classifica informações como nomes de pessoas, locais e organizações. Este serviço oferece um **limite gratuito de aproximadamente 5.000 textos por mês**, tornando-o uma excelente opção para quem está começando a explorar as funcionalidades de IA da Microsoft. Para acessá-lo, visite: [https://language.cognitive.azure.com](https://language.cognitive.azure.com).

###  2. Speech Studio

O Azure Speech Studio é a ferramenta ideal para trabalhar com a conversão de fala para texto e vice-versa. Ele permite a **transcrição de áudio para texto**, convertendo palavras faladas em texto escrito, e a **síntese de texto para voz**, transformando texto em fala com vozes naturais e personalizáveis. Este serviço possui um **limite gratuito de 5 horas de áudio para transcrição e 500 mil caracteres para síntese de voz**. É uma ferramenta poderosa para aplicações que envolvem interação por voz, como assistentes virtuais e sistemas de atendimento. Para começar a usar, acesse: [https://speech.microsoft.com](https://speech.microsoft.com).

###  3. Document Intelligence (Form Recognizer)

Anteriormente conhecido como Form Recognizer, o Azure Document Intelligence é especializado na **leitura e extração de dados de documentos**. Ele é capaz de processar diversos formatos, incluindo PDFs, e extrair informações estruturadas e não estruturadas de formulários, faturas, recibos e outros tipos de documentos. Este serviço também **possui uma camada gratuita**, permitindo que os usuários testem suas capacidades de reconhecimento óptico de caracteres (OCR) e extração de dados. Para explorar suas funcionalidades, visite: [https://formrecognizer.appliedai.azure.com](https://formrecognizer.appliedai.azure.com).

###  4. Azure AI Studio ( cuidado)

O Azure AI Studio é um ambiente abrangente que oferece um **Playground de IA** e a capacidade de **testar diversos modelos de inteligência artificial**. Embora seja uma ferramenta valiosa para experimentação e desenvolvimento, é importante ter **cuidado** ao utilizá-lo, pois **pode gerar custos rapidamente**. Os limites gratuitos podem não ser suficientes para testes extensivos, e o consumo de recursos pode escalar de forma inesperada. Portanto, é **recomendado usá-lo apenas para testes leves e controlados** para evitar cobranças indesejadas. Você pode acessá-lo em: [https://ai.azure.com](https://ai.azure.com).
